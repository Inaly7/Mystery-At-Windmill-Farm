# MissingEggDoc

公开的游戏设计文档库：**风车农场悬案 · 3D 轻量侦探游戏** 整体方案，Markdown 分区文档。使用**团结引擎 1.10.1** 开发，目标发布平台为 **Steam**，支持设备为 **PC**。

> **一句话项目定位**：面向 Steam 的 3D Lowpoly 探案小世界——玩家扮演一只名叫芦笛（Reed）的绿头鸭，在微缩农场中破解动物们的「跨服对话」，寻找母鸡淑芬丢失的、画有爱心标记的宝贝蛋；全流程真相与玩家认知存在刻意错位，终局以人类温柔介入完成情绪反转。初版曾上线抖音小火人世界，约五万人游玩并获得大量好评；初版使用 Lua 编写逻辑并存储数据，当前版本改为 C# 逻辑与 JSON 数据。
