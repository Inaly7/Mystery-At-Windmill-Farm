# 01 项目概述与目标

## 1.1 一句话定位

面向 **Steam**、支持 **PC** 的 **3D Lowpoly 探案小世界**：玩家扮演一只名叫芦笛（Reed）的**绿头鸭**，在一座充满戏剧张力的**微缩农场**中，通过收集线索、破解动物们的「跨服对话」，寻找母鸡**淑芬**丢失的、画有爱心标记的**宝贝蛋**（全流程真相与玩家认知存在刻意错位，终局收束为温柔反转）。使用**团结引擎 1.10.1** 开发。

## 1.2 品类与参考

- **品类融合**：治愈探索 + 荒诞推理 + 情感反转；轻量 3D 场景叙事 + 推理收集。
- **体验关键词**：「跨频道聊天」、冷幽默、官方吐槽、红鲱鱼高能误导、名场面。

## 1.3 设计目标与非目标

**目标**

- **核心体验**：治愈探索 + 荒诞推理 + 情感反转。
- **目标时长**：**约 1 小时**单线全流程。
- **平台**：目标发布平台为 **Steam**，支持设备为 **PC**；键鼠操作。内置多个**高能传播点**（如闪电蜗牛慢语速、悲伤蛙谜语、大黄醉狗翻身等——具体演出以 `07`/`09` 为准）。

**非目标**

- 不做重操作战斗主循环；不以数值养成为核心卖点。
- 不以全语音演出为硬性交付（听觉策略见 `11`）。

## 1.4 范围边界

- **叙事主骨架**：**两章**结构（天降大锅 → 红顶屋温柔反转）+ 尾声蜗牛收束；动物群像与物证链以 `05`/`06`/`07` 为准。

## 1.5 版本沿革

- **初版**：上线**抖音小火人世界**，约**五万人**游玩，获得大量好评。该版本使用 **Lua** 编写逻辑，并用 **Lua** 存储数据。
- **当前版本**：使用**团结引擎 1.10.1** 开发。运行逻辑改为 **C#**，运行时数据改为 **JSON**。目标发布平台为 **Steam**，支持设备为 **PC**。玩家化身为一只名叫芦笛（Reed）的**绿头鸭**。
