## 13.1 统一交互规则

- **走近**：进入交互范围，出现交互键（或地点特效）。
- **点击交互**：玩家**按下交互键**后播对话 / 调查 / 放置等（本库默认方式）。
- **强制播放**（全库仅下列，**不需按交互键**）：
  1. **黑猫 · 大树 1-A**：首次进入大橡树交互范围自动播伏笔句。
  2. **乌鸦 · 屋顶 2-A**：首次登顶到达屋顶自动播对峙（**不点乌鸦 NPC**）。
  3. **大黄 2-B 摇树 → 黑猫 2-A**：演出同链转接（玩家不另点黑猫进场）。
  4. **老鼠兄弟 · 0-A**：首次进入 **E39** 红顶屋墙缝外围大范围自动播吆喝（面向玩家 · 玩家搭两句；**不点墙缝**）。
- **同链**：已由强制播放或**点击 NPC / 环境点**开场后，紧接下一段对白不出菜单（如小鸡 **2-A**→**2-hub**、乌鸦 **2-A**→**2-B**）。
- **非强制**：含 E03 偷听、各 NPC 日常 hub、二周目结尾等——均为**到位后点交互键**，勿写「路过自动播」。
- **路径喊话强制播**：E35/E36（乌鸦）、E37/E38（黑猫）为进 Trigger **强制播**（一次性）；E37/E38 另须 `BlackCat_Entered`。
- **线索交互**：[`19-关键线索调查解谜`](./19-关键线索调查解谜.md) 指定的关键物证由环境点进入独立 2D 调查，关键证词在原段对白播毕后进入要点归位；成功后统一发放原线索、写入原状态与相关计数，并接原后续对白。其他线索使用线索大图 + 描述框，关闭后记录。笔记本承担取得后的记录与回看。
- **计数交互**：奶酪碎等计数点也走同一点击反馈；不设背包，只更新笔记本 / 计数状态。
- **空间闸**：首次点击给失败反馈；满足条件后再次点击执行放置、通路、跳跃或进入演出。
- **NPC 开口信息**：逐句文本放在对应 `characters/*-对话脚本.md`；本文只记录它们与环境点的解锁关系，避免同一句证词双维护。
- **点位三级标注**：
  - **【硬锁】**：直接影响对话、质询、空间通路或章节推进。
  - **【辅助】**：写入笔记本，不阻挡任何情节；补强推理密度或场景回扣。
  - **【氛围】**：只给描述反馈，**不写入笔记本**；纯粹扩充世界观与角色个性。
- **失败兜底**：主线硬锁只卡信息收集，不惩罚失败；薄荷鱼谜题失败后通过老鼠售后包兜底。
